# Настройка распознавания речи

Бот поддерживает распознавание голосовых сообщений через внешние API.

## Поддерживаемые провайдеры

### 1. OpenAI Whisper API (рекомендуется)
- **Точность**: Очень высокая
- **Языки**: Поддержка множества языков, включая русский
- **Стоимость**: ~$0.006 за минуту аудио
- **Регистрация**: https://platform.openai.com/

**Настройка:**
1. Зарегистрируйтесь на https://platform.openai.com/
2. Создайте API ключ в разделе API Keys
3. Добавьте в `.env`:
   ```
   OPENAI_API_KEY=sk-ваш-ключ-здесь
   SPEECH_PROVIDER=openai
   ```

### 2. Yandex SpeechKit
- **Точность**: Высокая для русского языка
- **Языки**: Русский, английский и другие
- **Стоимость**: Первые 1000 запросов бесплатно, затем ~0.5₽ за запрос
- **Регистрация**: https://cloud.yandex.ru/

**Настройка:**
1. Зарегистрируйтесь на https://cloud.yandex.ru/
2. Создайте сервисный аккаунт и получите API ключ
3. Добавьте в `.env`:
   ```
   YANDEX_API_KEY=ваш-api-ключ-здесь
   SPEECH_PROVIDER=yandex
   ```

## Автоматический выбор провайдера

Если установлен `SPEECH_PROVIDER=auto`, бот будет использовать первый доступный API:
1. OpenAI (если настроен OPENAI_API_KEY)
2. Yandex (если настроен YANDEX_API_KEY)

## Установка зависимостей

```bash
pip install openai  # Для OpenAI Whisper API
# или
pip install -r requirements.txt  # Установит все зависимости
```

## Проверка работы

1. Откройте бота
2. Нажмите "📝 Создать заказ"
3. Выберите "🎤 Голосовое сообщение"
4. Отправьте голосовое сообщение
5. Бот должен распознать текст автоматически

## Примечания

- Формат аудио: OGG Opus (стандартный формат Telegram)
- Максимальная длительность: зависит от API (обычно до 25 МБ)
- Язык распознавания: русский по умолчанию, можно изменить в коде
